# Köşe Bakkal

Mahalle bakkalını işlettiğin 3B bir oyun. Ürün topla, rafları doldur, kasada müşterilere bak, çalışan tut ve dükkânı büyüt.

## Telefonda oynama

1. Bu deponun GitHub Pages adresini iPhone'da Safari ile aç.
2. Paylaş düğmesine dokun.
3. Ana Ekrana Ekle'yi seç.

Oyun ana ekrandaki simgesinden tam ekran açılır. İlk açılıştan sonra internetsiz de çalışır.

## GitHub Pages'i açma

1. Deponun **Settings** sayfasını aç.
2. **Pages** bölümünde kaynak olarak **Deploy from a branch** seç.
3. Dal olarak **main**, klasör olarak **/ (root)** seç ve kaydet.
